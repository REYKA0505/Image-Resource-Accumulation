## 来源与许可

图库中的图片来自开放论文的图件，保留了论文标题、图号、图注、原图链接和文章级许可。完整记录见 [来源清单](来源清单.json)。

当前图片为原图的缩放预览，所选论文的文章级许可为 CC BY 4.0。个别图片可能包含另有许可的第三方材料；引用、改编或公开传播前，请核对该图的原始图注和许可。

主题分类根据论文内容整理，图形线索根据图注关键词自动识别，可能漏标或误标。欢迎在新增图例时保留 DOI、图号、作者、期刊及具体许可。
